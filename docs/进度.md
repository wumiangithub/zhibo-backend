## 已核实的微吼事实

- 域名：`https://saas-open.vhall.com`
- `POST` + `application/x-www-form-urlencoded` + UTF-8；部分接口为 **GET + query**（如 get-role-url、get-token 拼嵌入）
- 头：`platform: 15`，`request-id` 每次唯一
- 公共参数：`app_key`、`sign_type`(0=MD5)、`signed_at`、`sign`
- 签名：除 `sign` 外参数按名升序拼 `名+值`，首尾加 secret，MD5 小写；数组只签 key。文档：[签名机制](https://saas-doc.vhall.com/opendocs/show/1423)
- 成功：`code=200`（我们对外 API 仍用 `code=0`）

| 功能 | 路径 | 要点 |
|------|------|------|
| 创建活动 | `POST /v3/webinars/webinar/create` | subject、start_time、webinar_type 必填；`start_time` 为 `Y-m-d H:i`（不要秒） |
| 活动列表 | `POST /v3/webinars/webinar/get-list` | pos、limit(≤100) 必填 |
| 活动详情 | `POST /v3/webinars/webinar/info` | webinar_id；`full_embed_share_link`、`pv` |
| 主持人开播 | `GET /v3/webinars/live/get-role-url` | webinar_id + type=1 → `page_url` |
| 控制台 token | `POST /v3/users/open-user/get-token` | 拼管理后台嵌入 URL |
| 当前在线 | `POST /v3/data-center/webinar/current-online-number` | → `num`；约 1 次/分钟 |
| 在线趋势 | `POST /v3/data-center/report/online` | start/end 跨度 ≤1 天 |

`webinar_state`：`0全部 1直播 2预告 3结束 4点播 5回放`

### 已落地对外 API

| 服务 | 方法 | 路径 | 说明 |
|------|------|------|------|
| admin | POST | `/api/activities` | body: `title`,`startTime`,`type` → `{id}` |
| admin | GET | `/api/activities` | query: `page`,`pageSize`,`keyword`,`state` |
| admin | GET | `/api/activities/{id}` | 详情 |
| admin | GET | `/api/activities/{id}/host` | → `{hostUrl}` |
| admin | GET | `/api/activities/{id}/embed` | → `{embedUrl}`（控制台 token） |
| admin | GET | `/api/activities/{id}/stats` | → `{id,title,state,type,pv,onlineCount}` |
| admin | GET | `/api/activities/{id}/stats/online` | query: `startTime`,`endTime` → 分钟级在线点 |
| live | GET | `/api/watch/{id}` | query: `guestId?`,`nickname?` → 已拼身份的 `embedUrl` |
