### 本站库

- MySQL 库名 `zhibo`；连接见仓库根 `.env` 的 `MYSQL_*`
- 表 `activity`：PK UUID；`provider` + `provider_room_id`；V6 起联合唯一 `uk_activity_provider_room`；Flyway V1 + V6。V9 增加 `shelf_status` / `risk_status` / `sell_type` / `validity_label` / `deleted_time`（已有行回填已上架、已通过、免费、长期有效）。V10 增加 `auto_list`、售卖价/划线价/密码密文、访问有效期、回放开关/有效期/倍速/快进（已有行回填 auto_list=false、回放开启+永久+倍速/快进允许）。**V25（D59）**：本站时间列 `*_at`→`*_time`，接口 JSON 对应 `*Time`；微吼 `signed_at` 等第三方字段不改
- 表 `activity_owner` / `activity_product` / `activity_audit`：Flyway V9。归属人只存员工 id；商品只存 `spu_id` + 名称快照。V19 给 `activity_audit` 加 `action`（submit/audit），`result` 可空；历史场次回填一条发起申请
- 表 `activity_member`：Flyway V23。主播/助理/嘉宾（`role` 1/2/3）；V10 的 `activity_host` 迁入 `role=1` 后 DROP。V35 回填历史空 nickname/avatar_url。`activity_courseware` 仍 V10（material_id + name/url/type 快照 + sort_order）
- 表 `room_attendance`：唯一键 `(room_id, user_id)`（`uk_room_user`）；Flyway `V5__room_attendance_one_row_per_user.sql`
- 表 `presence_event`：进出流水；`uk_presence_mid`；客户端去重 `(room_id,user_id,type,event_time,source)`；Flyway V6
- 表 `flyway_schema_history`：Flyway 自建迁移记账本（非业务）；V7 补中文表/字段注释
