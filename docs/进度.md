## 已核实的微吼事实

- 域名：`https://saas-open.vhall.com`
- `POST` + `application/x-www-form-urlencoded` + UTF-8；部分接口为 **GET + query**（如 get-role-url、get-token 拼嵌入）
- 头：`platform: 15`，`request-id` 每次唯一
- 公共参数：`app_key`、`sign_type`(0=MD5)、`signed_at`、`sign`
- 签名：除 `sign` 外参数按名升序拼 `名+值`，首尾加 secret，MD5 小写；数组只签 key。文档：[签名机制](https://saas-doc.vhall.com/opendocs/show/1423)
- 成功：`code=200`（我们对外 API 仍用 `code=0`）

| 功能 | 路径 | 要点 |
|------|------|------|
| 创建活动 | `POST /v3/webinars/webinar/create` | subject、start_time（`Y-m-d H:i`）、webinar_type 1/2/3；可选 introduction、img_url、**`no_delay_webinar`（0/1 ← 本站 `ultraLowLatency`）** |
| 创建点播 | `POST /v3/webinars/webinar/create-demand` | 必填 subject、introduction、record_id、webinar_curr_num；本站 type=4 |
| 图片上传 | `POST /v3/commons/upload/index` | multipart；`type=image`；**`resfile` 不参与签名** → `domain_url`；本站 `POST /api/uploads/image` 已代理 |
| 活动列表 | `POST /v3/webinars/webinar/get-list` | pos、limit(≤100) 必填（本站列表现从库读） |
| 活动详情 | `POST /v3/webinars/webinar/info` | webinar_id；`full_embed_share_link`、`pv` |
| 改活动 | `POST /v3/webinars/webinar/edit` | webinar_id + subject / start_time / introduction / **`img_url`←coverUrl** |
| 结束直播 | `POST /v3/webinars/live/end` | webinar_id |
| 删除活动 | `POST /v3/webinars/webinar/delete` | **`webinar_ids`** |
| 主持人开播 | `GET /v3/webinars/live/get-role-url` | webinar_id + type=1 → `page_url` |
| 控制台 token | `POST /v3/users/open-user/get-token` | 拼管理后台嵌入 URL |
| 当前在线 | `POST /v3/data-center/webinar/current-online-number` | → `num`；约 60s 缓存 |
| 在线趋势 | `POST /v3/data-center/report/online` | 跨度 ≤1 天；`Y-m-d H:i:s` |
| 回放列表 | `POST /v3/webinars/record/get-list` | webinar_id + pos/limit；`id`→create-demand 的 record_id；本站 `GET /api/activities/{uuid}/records` |
| 聊天审核页 | `POST /v3/webinars/manage/chat-filter` | webinar_id + email + name(≤30) → `page_url`；本站 `GET /api/watch/{uuid}/chat-filter`；默认 email=`assistant@zhibo.local`、name=`助理` |

`webinar_state`：`0全部 1直播 2预告 3结束 4点播 5回放`

### 本站库

- MySQL 库名 `zhibo`；连接见仓库根 `.env` 的 `MYSQL_*`
- 表 `activity`：PK UUID；`provider` + `provider_room_id`；V6 起联合唯一 `uk_activity_provider_room`；Flyway V1 + V6。V9 增加 `shelf_status` / `risk_status` / `sell_type` / `validity_label` / `deleted_at`（已有行回填已上架、已通过、免费、长期有效）
- 表 `activity_owner` / `activity_product` / `activity_audit`：Flyway V9。归属人只存员工 id；商品只存 `spu_id` + 名称快照
- 表 `room_attendance`：唯一键 `(room_id, user_id)`（`uk_room_user`）；Flyway `V5__room_attendance_one_row_per_user.sql`
- 表 `presence_event`：进出流水；`uk_presence_mid`；客户端去重 `(room_id,user_id,type,event_time,source)`；Flyway V6
- 表 `flyway_schema_history`：Flyway 自建迁移记账本（非业务）；V7 补中文表/字段注释
