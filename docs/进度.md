## 已核实的微吼事实

- 域名：`https://saas-open.vhall.com`
- `POST` + `application/x-www-form-urlencoded` + UTF-8
- 头：`platform: 15`，`request-id` 每次唯一
- 公共参数：`app_key`、`sign_type`(0=MD5)、`signed_at`、`sign`
- 签名：除 `sign` 外参数按名升序拼 `名+值`，首尾加 secret，MD5 小写；数组只签 key。文档：[签名机制](https://saas-doc.vhall.com/opendocs/show/1423)
- 成功：`code=200`（我们对外 API 仍用 `code=0`）

| 功能 | 路径 | 要点 |
|------|------|------|
| 创建活动 | `POST /v3/webinars/webinar/create` | subject、start_time、webinar_type 必填 |
| 活动列表 | `POST /v3/webinars/webinar/get-list` | pos、limit(≤100) 必填 |

`webinar_state`：`0全部 1直播 2预告 3结束 4点播 5回放`
